# reality-stories

Scary and interesting short stories for TikTok and Instagram, made and scheduled by Claude.

- `CLAUDE.md`: how the daily autopilot run works (read this first)
- `pipeline/`: shared tools (voice, render, sound, cover, scaffolding)
- `stories/`: one folder per story (source for the video)
- `videos/`, `covers/`: finished files that Metricool pulls from
- `ops/schedule.md`: the posting calendar; `ops/ideas.md`: done, skip list, and idea bank
